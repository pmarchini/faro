# Proposals

This directory is the project pipeline for proposal-driven work.

Status is represented by directory location:

- `drafts/`: exploratory specs that are still under discussion and are not yet accepted into the execution pipeline
- `todo/`: accepted ideas that are not active yet
- `in-progress/`: the currently active or partially executed proposals
- `done/`: completed or explicitly closed proposals

Rules:

- keep one proposal per markdown file
- keep draft proposals in `drafts/` until they are explicitly accepted
- move proposal files between status directories instead of duplicating them
- keep proposal status aligned with the actual implementation state
- update the active proposal when scope, risks, or acceptance criteria change
