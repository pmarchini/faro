Resolve the next path step

This pane turns graph selection into a reading target. It makes graph mode useful even when the user wants to stay anchored in code and prose rather than spatial navigation. 

export function traversePath(document, current, direction) {
  if (direction === "next") {
    return pathMachine.next(document, current)
  }

  return pathMachine.previous(document, current)
}
Why it matters

The workbench is the safest migration path from today's Faro UI because it preserves the reading-centric surface area while adding graph awareness.
